# ANGSI JR. V10.2 | November 2026

Based on V10.1 full app. Original navigation and existing 4D QC, horizon viewer, well correlation, original V10.1 and evidence ranking preserved.

1. Additional Opportunities dashboard: uniform reservoir log controls (same base properties for all polygons within an interval), editable facies multipliers, gross-thickness cap OFF by default, Bo/Bg/recovery scenario controls, phase alternatives, source transparency and CSV.
2. Calculated gas GIIP **MMscf**, oil STOIIP **MMstb**, in-place **MMboe**, and optional separately identified recoverable / remaining recoverable scenarios (only after verified user production input). No target volume forced.
3. Green volume-scaled map bubbles, explicit values, ranked Top 3, per-reservoir totals, and batch adjacent marker-interval screening over full sampled seismic footprint.
4. Prevents false summing of overlapping interval volumes by measured marker ordering QC. These are candidate anomaly footprints, not geological closures.
5. Seismic QC GR and RT curve colour pickers, moved E–W extension control below seismic.
6. GeoCopilot local science fallback for unavailable model, curated public citations, optional Crossref bibliography metadata search, and non-scrolling vertical chat container.
7. Targeted tests (28) and Python syntax checks passed locally. No claim of end-to-end Angsi SEG-Y/HPC verification.
